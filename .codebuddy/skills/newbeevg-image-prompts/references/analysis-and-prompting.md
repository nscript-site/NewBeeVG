# 文字稿分析与提示词编写

## 1. 素材识别清单

通读文字稿，按章节记录可视觉化的内容：

| 类型 | 判断标准 | 例子 |
| --- | --- | --- |
| 历史场景 | 有明确时代、地点、事件 | 17 世纪曼哈顿木栅栏 |
| 地点/建筑 | 有空间结构与环境 | 港口、交易所、工厂、街道 |
| 人物 | 有身份、动作、服装、情绪 | 商人、航海家、工程师 |
| 器物/产品 | 有外观、材质、使用方式 | 罗盘、航海图、咖啡杯 |
| 地图/路线 | 有地理关系、路径 | 贸易航线、迁徙路线 |
| 图表/示意 | 有数据关系、流程、对比 | 增长曲线、产业链 |
| 关键意象 | 能承载主题的视觉隐喻 | 潮水、齿轮、桥梁 |

不适合配图：

- 纯观点、口号、重复解释；
- 没有具体视觉信息的过渡句；
- 需要实时数据但无法核实的图表；
- 涉及真实人物、隐私、未授权品牌的内容。

## 2. 数量与节奏

- 每个主要章节 1–2 张；
- 长段落优先选一个“叙事支点”，不要逐句配图；
- 连续相似场景只保留一张，或用不同构图区分；
- 片头/片尾可各有一张主视觉；
- 图太少会显得空，图太多会打断口播节奏。

## 3. 全局风格

风格写在 `prompts.md` frontmatter：

```yaml
---
style: 金融史口播风格插图
---
```

好的风格名：

- 说明媒介：插画、摄影、蚀刻、信息图、3D 渲染；
- 说明色彩/光线：复古色调、柔和自然光、深色科技感；
- 说明用途：口播插图、历史复原、产品发布。

示例：

```text
金融史口播风格插图
科技产品发布会视觉
极简科普信息图
温暖手绘人物插画
暗色电影概念设计
```

## 4. 提示词结构

推荐顺序：

```text
时间/地点/事件
+ 主体与动作
+ 构图/镜头
+ 环境与细节
+ 光线/色彩
+ 媒介/风格
+ 质量与限制
```

示例：

```text
1653年新阿姆斯特丹，华尔街原始防御木栅栏，尖顶粗原木栅栏，原木风化褪色，底部带夯土堤和浅壕沟，沿着曼哈顿南端横向延伸，远处是荷兰风格尖顶山墙小木屋、阿姆斯特丹堡，海面有荷兰帆船，17世纪北美殖民场景，柔和自然光，历史复原插画，细腻写实，复古色调，干净画面，无现代建筑，无多余杂物
```

拆解：

| 部分 | 内容 |
| --- | --- |
| 时间/地点 | 1653 年新阿姆斯特丹 |
| 主体 | 华尔街原始防御木栅栏 |
| 细节 | 尖顶粗原木、风化褪色、夯土堤、浅壕沟 |
| 构图 | 沿曼哈顿南端横向延伸 |
| 环境 | 荷兰山墙小木屋、阿姆斯特丹堡、帆船 |
| 光线/风格 | 柔和自然光、历史复原插画、复古色调 |
| 限制 | 无现代建筑、无多余杂物 |

## 5. 分类型写法

### 历史场景

```text
1600年荷兰港口清晨，木制起重机正在卸货，穿宽檐帽和长外套的商人站在码头清点木箱，远处是尖顶仓库和帆船，薄雾，低角度广角，历史复原插画，细腻写实，暖灰色调，无现代建筑，无现代服装，无水印
```

### 地图/航线

```text
1600年荷兰航海图，泛黄羊皮纸，精致八角罗盘，带风向玫瑰，彩色绘制大陆和岛屿轮廓，红色航线路径，浅蓝表示海洋，手绘帆船、美人鱼、海怪装饰，花体荷兰文字地名，装饰性边框，古旧褪色色调，历史航海复刻图，蚀刻手绘，高清，2K
```

- 写“历史复原图/示意图”，不要声称是精确史料；
- 不确定的边界、地名、数据不要编造；
- 需要文字时，明确写“荷兰文字地名”之类的风格，而不是要求准确拼写。

### 人物

```text
19世纪伦敦咖啡馆内，一位穿深色礼服的中年商人坐在窗边，手边放着账本和怀表，侧逆光，背景有模糊的交谈人群，浅景深，纪实肖像，复古胶片质感，低饱和，无现代物品，无水印
```

- 避免真实人物姓名与可识别肖像；
- 写清时代服装、道具、环境；
- 需要情绪时用动作和光线表达，不要只写“很有氛围”。

### 产品/器物

```text
白色陶瓷咖啡杯，杯口细微高光，放在深色胡桃木桌面，旁边散落几颗咖啡豆，正面平视，柔和棚拍光，浅景深，极简产品摄影，真实材质，干净构图，1:1 方图，无文字，无logo
```

### 数据/流程示意

```text
深色科技感数据可视化背景，中心留出大面积空白，四周有细线网格、发光节点和抽象上升曲线，低对比，简洁，信息图底图，16:9 横版，无具体数字，无文字，无logo
```

- 生成图不擅长精确数字；优先做“底图/示意”，数字和标签后期叠加；
- 明确“无具体数字/无文字”，避免乱码。

### 抽象概念

```text
一条由旧地图碎片组成的河流穿过现代城市，河流象征资本流动，冷蓝与暖橙对比，超现实拼贴插画，中心构图，干净背景，概念视觉，无文字，无水印
```

抽象概念要有具体视觉载体，不要只写“表现增长”“体现信任”。

## 6. 负面约束

按需选择，不要全部堆上：

```text
无现代建筑，无现代物品，无现代服装，无文字，无水印，无logo，无多余杂物，无畸形手指，无低清晰度，无过曝
```

人物图可加：

```text
无多余肢体，无面部崩坏，无塑料皮肤
```

历史图可加：

```text
无电线，无汽车，无现代招牌
```

## 7. 文件命名

- 小写 ASCII：`wall.jpg`、`trade-route.jpg`；
- 避免：`古代华尔街.jpg`、`image 1.jpg`、`final-final.jpg`；
- 默认 `.jpg`；透明背景用 `.png`；
- 同一份 prompts.md 内不重名；
- 路径写 `./文件名`，不要写子目录。

## 8. 与 Seedream 对接

`prompts.md` 生成后，可把每个条目交给 `doubao-seedream-5-flash` 技能：

```bash
python scripts/generate_image.py \
  --prompt "<条目提示词>" \
  --output assets/images/wall.jpg \
  --size 2K \
  --ratio 16:9
```

- `style` 是全局风格，不一定要逐字塞进每条提示词；
- 生成时按图片用途选择比例：横版口播 16:9，竖版 9:16，方图 1:1；
- 生成后检查文字、手部、时代道具与地图准确性；
- 需要重做时换文件名，避免覆盖已选素材。
