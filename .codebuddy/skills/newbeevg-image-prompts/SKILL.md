# NewBeeVG 图像素材提示词生成

## 用途

输入一个视频文字稿 Markdown，分析其中需要配图的场景，输出一份可直接用于文生图的 `prompts.md`：

- 每个素材一个中文简介、一个文件名、一个中文提示词；
- 全局风格写在 YAML frontmatter；
- 文件固定输出到**视频脚本所在目录**的 `assets/images/prompts.md`；
- 只生成提示词，不直接生成图片。

## 输入与输出

### 输入

- 文字稿/口播稿 `.md` 文件；
- 可包含标题、章节、段落、旁白、已有图片引用或 frontmatter；
- 视频脚本目录 = 输入 Markdown 所在目录。

### 输出

```text
<视频脚本目录>/
└── assets/
    └── images/
        ├── prompts.md       # 本技能生成
        ├── wall.jpg         # 后续生成
        └── nautical_chart.jpg
```

`prompts.md` 固定格式：

```markdown
---
style: 金融史口播风格插图
---

!(古代华尔街的木墙)[./wall.jpg]

1653年新阿姆斯特丹，华尔街原始防御木栅栏，尖顶粗原木栅栏，原木风化褪色，底部带夯土堤和浅壕沟，沿着曼哈顿南端横向延伸，远处是荷兰风格尖顶山墙小木屋、阿姆斯特丹堡，海面有荷兰帆船，17世纪北美殖民场景，柔和自然光，历史复原插画，细腻写实，复古色调，干净画面，无现代建筑，无多余杂物

!(航海图)[./nautical_chart.jpg]

1600年荷兰航海图，泛黄羊皮纸，精致八角罗盘，带风向玫瑰，彩色绘制大陆和岛屿轮廓，红色航线路径，浅蓝表示海洋，手绘帆船、美人鱼、海怪装饰，花体荷兰文字地名，装饰性边框，古旧褪色色调，历史航海复刻图，蚀刻手绘，高清，2K
```

格式要求：

- frontmatter 只写全局 `style`；
- 每个素材使用 `!(中文简介)[./文件名.jpg]`；
- 下一段是中文提示词；
- 条目之间空一行；
- 不要添加 `#` 标题、列表、代码块或额外说明；
- 输出顺序与文字稿叙事顺序一致。

## 工作流

### 1. 读取文字稿

提取：

- 主题、时代、地点、人物；
- 章节结构与叙事顺序；
- 语气与受众（历史科普、财经口播、产品介绍、教程…）；
- 已有图片、`assets/README.md`、已有 `prompts.md`。

### 2. 确定全局风格

优先复用文字稿已有的 `style`；没有时，根据内容归纳一个简短、可复用的风格名：

```text
金融史口播风格插图
科技产品发布会视觉
极简科普信息图
温暖手绘人物插画
```

风格应能统一整组素材的媒介、色彩、光线与质感，不要每个素材换一种画风。

### 3. 判断需要哪些图像素材

优先选择**可被画出来、能帮助理解叙事**的内容：

- 具体历史场景、地点、建筑、器物；
- 人物肖像、人物动作、服装与生活场景；
- 地图、航线图、贸易路线、历史复原图；
- 产品图、使用场景、拆解图；
- 数据关系示意图、流程示意图、对比图；
- 封面/片头主视觉、章节过渡的关键意象。

不要为以下内容强行配图：

- 纯抽象概念、口号、重复旁白；
- 一句话就能说清且没有画面的过渡句；
- 每段都配图导致信息过载；
- 需要精确数据但无法核实的图表；
- 涉及真实人物肖像、隐私或未授权品牌时，先确认授权。

数量建议（不是硬限制）：

| 文字稿长度 | 建议素材数 |
| --- | --- |
| < 800 字 | 2–5 |
| 800–2000 字 | 4–8 |
| 2000–5000 字 | 6–12 |
| > 5000 字 | 每个主要章节 1–2 张，避免无意义堆图 |

同一个概念只保留一张；如果已有同名图片，复用，不重复生成。

### 4. 规划文件名

- 使用 ASCII 小写字母、数字、下划线或短横线；
- 不带中文、空格、括号；
- 默认 `.jpg`；需要透明背景时用 `.png`；
- 名称体现内容：`wall.jpg`、`nautical_chart.jpg`、`trade-route.jpg`；
- 同一份 `prompts.md` 内文件名必须唯一；
- 路径统一写 `./文件名`，图片与 `prompts.md` 同目录。

### 5. 编写中文提示词

按以下顺序组织，写成一段连续中文，不用列表：

1. **时间/地点/事件**：1653 年新阿姆斯特丹、1600 年荷兰；
2. **主体与动作**：木栅栏、航海图、人物、产品；
3. **构图与镜头**：横向延伸、近景、俯视、广角、中心构图；
4. **环境与细节**：夯土堤、帆船、罗盘、航线、材质；
5. **光线与色彩**：柔和自然光、复古色调、深蓝与橙红对比；
6. **媒介与风格**：历史复原插画、蚀刻手绘、产品摄影、信息图；
7. **质量与限制**：高清、2K、干净画面、无现代建筑、无文字、无水印。

要求：

- 具体、可画，避免“震撼”“高级感”等空泛词；
- 建议 80–200 个中文字符；
- 历史场景要写清时代特征，并加“无现代建筑/无现代物品”；
- 地图/图表写“示意图/历史复原图”，不要编造精确数据；
- 画面文字尽量少；必须出现时用引号写准确内容，并说明位置；
- 负面约束按需添加，不要堆一长串互相矛盾的词；
- 全局风格已在 frontmatter，提示词重点描述本张画面的独有内容。

### 6. 写入 prompts.md

输出到输入 Markdown 所在目录的：

```text
<视频脚本目录>/assets/images/prompts.md
```

目录不存在时创建。

如果 `prompts.md` 已存在：

1. 先读取现有条目；
2. 保留仍然适用、经过人工修改的条目；
3. 只为新增素材追加条目；
4. 需要整体重写时，先备份为 `prompts.md.bak`；
5. 不要删除已有图片文件。

### 7. 校验

使用本技能的校验脚本：

```bash
python scripts/validate_prompts.py <视频脚本目录>/assets/images/prompts.md
```

检查项：

- frontmatter 是否有 `style`；
- 是否至少有一个 `!(简介)[./文件名]`；
- 简介、提示词是否非空；
- 文件名是否以 `./` 开头、后缀是否为 `.jpg/.jpeg/.png`；
- 文件名是否重复；
- 是否误用了子目录或中文文件名；
- 可选 `--check-images` 检查图片是否已经存在。

校验通过后再交给 `doubao-seedream-5-flash` 技能生成图片。

## 素材选择示例

| 文字稿内容 | 建议素材 |
| --- | --- |
| “1653 年，荷兰人在曼哈顿南端竖起木栅栏” | 17 世纪木栅栏复原图 |
| “这张航海图记录了荷兰商船航线” | 古航海图/航线示意图 |
| “公司营收连续三年增长” | 简洁增长曲线/数据示意图 |
| “他把杯子放在桌上，开始讲述” | 人物近景+桌面环境 |
| “这意味着一种全新的商业模式” | 抽象概念示意图，谨慎配图 |

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 每个段落都配图 | 只保留关键场景，按章节节奏控制数量 |
| 提示词空泛 | 补时间、地点、主体、构图、材质、光线 |
| 画风不统一 | 统一 frontmatter 的 `style`，提示词复用同一媒介与色调 |
| 文件名含中文/空格 | 改成小写 ASCII 与下划线/短横线 |
| 地图数据不准确 | 写成“示意图/历史复原图”，不要伪造精确数字 |
| 图片文字乱码 | 提示词尽量要求无文字；必须有时用引号写准确内容 |
| 覆盖了手工修改 | 先读旧 `prompts.md`，只追加或先备份 |
| 提示词与图片对不上 | 检查简介、文件名、提示词三者是否描述同一素材 |
