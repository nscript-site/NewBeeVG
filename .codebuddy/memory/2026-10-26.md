- 逻辑：路径为空 → 保留默认时长；文件不存在 / 扩展名不是 `.mp3`/`.wav` / `stage.FrameRate <= 0` → 打印警告并返回；否则用 NAudio `AudioFileReader` 读取 `TotalTime`，`DurationFrames = Math.Max(1, (int)Math.Ceiling(duration.TotalSeconds * fps))`（向上取整覆盖最后一帧）。

## NBAudioClip.ExportStereoPcm 实现
- 文件：`sources/NewBeeVG/Core/NBAudioClip.cs`。
- 使用 NAudio `AudioFileReader`（输出 float 样本）+ `WdlResamplingSampleProvider` 重采样到目标采样率（默认 44100）。
- 输出交错立体声 `float[]`：`[L0, R0, L1, R1, ...]`；单声道复制到左右声道，多声道只取前两路。
- 按预计时长预分配，读取中按需翻倍扩容，最后按实际帧数截断；异常/缺文件/`_error`/非法采样率返回 `null` 并打印提示。
- 校验：`read_lints` 无诊断。

## StereoPcmDataSet.Mixing 实现
- 文件：`sources/NewBeeVG/Base/StereoPcmSet.cs`。
- 逻辑：按 `SampleRate / FrameRate` 把每个片段的 `Frame` 换算为采样点偏移（四舍五入，负帧按 0）；输出长度取所有片段 `offset + 采样帧数` 的最大值；交错立体声逐样本累加；最后逐样本 `Math.Clamp(-1, 1)` 限幅。
- 返回 `StereoPcmData { Pcm = 输出, Frame = 0 }`；`IsEmpty`/无有效数据返回 `null`；非法采样率/帧率抛 `InvalidOperationException`；超大结果（> int.MaxValue/2 帧）抛异常。
- 校验：`read_lints` 无诊断。
