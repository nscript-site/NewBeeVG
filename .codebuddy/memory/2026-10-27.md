## 规则：AI 不得把 debug 设为 false
- 测试文件中的 `SkiaAnim(...).AsClip(...)` 是真实场景生产代码，不加 `debug` 条件；`debug = false` 时由结尾 `run(...)` 直接出片。
- AI 编写、测试、编译验证期间必须保持 `bool debug = true;`，**禁止改为 false**；false 仅由使用者交付后手动切换。
- 已同步 `SKILL.md`（debug 说明、工作流规则、关键约束、检查清单）、`references/api-and-pitfalls.md`（要点）、`assets/MyAnimation_Test.cs`（注释）。

## 规则：循环测试用例的守卫位置
- 问题：AI 把整个 `foreach` 包进 `if (debug == true)`，导致 `debug = false` 时 `SkiaAnim` 不注册片段。
- 正确结构：循环参数在守卫块外准备；每次迭代内 `if (debug == true) { using var probe = ...; probe.SavePNG(...); }`；随后无条件 `SkiaAnim(new Xxx(...)).AsClip(Frames, name: $"key_{key}")`。
- `SkiaAnim` 必须重新 `new`，不能复用守卫块内已释放的 `probe`；`name` 带循环键避免重名。
