## Methods.run 注释补充
- 文件：`sources/NewBeeVG/Methods.cs`，函数 `public static int run(NBStage, IList<NBClip>, IList<NBClip>[]?, string[]?)`。
- 补充 XML 文档与行内注释，明确 `args` 三种用途：
  - null/空 → `start()` 打开 Avalonia 预览窗口（阻塞），返回 -1；
  - 长度 1 → `args[0]` 为 MP4 路径，调用 `save()`（拒绝覆盖、依赖 ffmpeg），返回总帧数；
  - 长度 ≥2 → `args[0]` 帧号、`args[1]` PNG 路径，帧号非法返回 -1，越界仅提示，返回总帧数。
- 同时说明 `clipLists` 会 Prepare 后合并到同一轨道；Prepare 失败只打印不中断；PNG 走 `DrawingHelper.Save` 自动建目录。
- `read_lints` 无诊断。
